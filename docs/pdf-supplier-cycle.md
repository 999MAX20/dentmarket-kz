# PDF supplier cycle

Этот сценарий проверяет путь поставщика с реальными PDF-файлами без юридического эффекта и без публикации тестовой карточки в каталоге.

## Запуск

Перед запуском API должен иметь `SIGNATURE_CALLBACK_SECRET`. Для локального API:

```bash
SIGNATURE_CALLBACK_SECRET="local-signature-callback-secret-2026" \
  pnpm --filter @marketplace/api start

pnpm verify:supplier-cycle:pdf \
  "/path/to/price-list.pdf" \
  "/path/to/image-catalog.pdf"
```

Скрипт отправляет HMAC-подписанные callback-события для обеих подписей договора. Он использует тестовые организации, сертификаты и lot-данные; эти данные не являются юридическими документами.

## Проверяемые гарантии

- текстовый PDF извлекается в строки и не записывает неподтверждённую валюту в `priceMinor`/`currency`;
- PDF без текстового слоя получает `REVIEW_REQUIRED`, не создаёт выдуманные строки и не обрабатывается до OCR/ручного маппинга;
- совпадение по SKU/GTIN привязывается к существующей карточке, а не создаёт дубль;
- публикация предложения блокируется до действующего договора и двух проверенных ЭЦП;
- лицензируемая позиция блокируется до проверенного разрешительного документа, партии и регистрационного удостоверения;
- после всех проверок предложение может пройти публикацию, а тестовый прогон завершает его скрытием;
- результат сохраняется локально в `outputs/pdf-supplier-cycle-20260717/verification.json`.
