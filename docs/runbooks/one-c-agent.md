# 1С Agent runbook

1. Установить подписанный Agent через installer, проверить checksum и поддерживаемую версию. Для каждого из 30 подготовленных tenant-манифестов уже зафиксированы mapping и safety-gates в `data/integrations/one-c/supplier-manifests.json`.
2. Создать в 1С отдельного ограниченного пользователя; секрет не хранить в открытом виде.
3. Выполнить одноразовый enrollment, heartbeat и diagnostic report.
4. Настроить mapping складов, видов цен, номенклатуры, контрагентов и статусов заказа.
5. Прогнать 10–50 товаров: каталог, цена, остаток, партия; затем заказ, резерв, подтверждение, отмена и release.
6. Отключить сеть, проверить offline, retry и отсутствие дублей после восстановления.
7. Проверить auto-update/rollback Agent и восстановление после backup.
8. После успешного test sync поставщик больше не выгружает прайс вручную: 1С Agent забирает задания через исходящий HTTPS pull-протокол и регулярно передаёт каталог, цену, остатки, склады и статусы заказов.
9. Без реального binary и базы 1С статус остаётся `CONNECTOR_NEEDED`, даже если серверный протокол работает. Нельзя объявлять поставщика `LIVE_VERIFIED` только на основании манифеста.
