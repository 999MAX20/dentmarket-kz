# ADR 001: Модульный монолит

## Статус

Принято.

## Решение

Backend запускается как один NestJS deployable с изолированными доменными модулями. События между модулями публикуются через transactional outbox. Payments, Search и Integrations могут быть выделены после появления измеримой операционной причины.

## Последствия

Транзакции и локальная разработка остаются простыми. Границы модулей контролируются интерфейсами и тестами, а не сетевыми вызовами.
