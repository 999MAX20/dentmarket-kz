# ADR 002: Гибридный каталог

## Статус

Принято.

## Решение

Идентичность товара и часто фильтруемые поля хранятся в типизированных колонках. Динамические атрибуты используют типизированные value columns. JSONB разрешён для raw и внешних payload. Поиск использует отдельную проекцию PostgreSQL.

## Последствия

Схема сложнее простого JSON-документа, но сохраняет типизацию, индексацию, аналитику и отраслевую расширяемость.
